# 📘 Day 06 — Strings & Immutability

## Topics Covered
- String creation & memory (Heap vs String Pool)
- Immutability of String
- == vs equals()
- Common String methods
- String vs StringBuilder performance

## Key Takeaways
- Strings are immutable by design
- Use equals() for comparison
- StringBuilder is best for frequent modifications
- Immutability improves security & performance

## Real-World Use
- Secure data handling
- Efficient text processing
- Avoiding memory leaks
