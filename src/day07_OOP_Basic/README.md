# Encapsulation:
Encapsulation is the process of hiding internal data and allowing access only through controlled methods.
### 🚀 Why Encapsulation Matters in Backend

* Prevents invalid state
* Easier debugging
* Secure code
* Mandatory for Spring, Hibernate, APIs

# Inheritance:
Inheritance means Child class reuses properties and methods of parent class.
* extends keyword creates IS-A relationship
* Child class can access public & protected members
* Code reuse = main benefit
* One parent, multiple children possible

# Polymorphism

* Polymorphism means “one reference, many forms”.

* It allows a parent class reference to point to different child class objects.

* The same method call can behave differently based on the object type.

* Polymorphism is achieved mainly through method overriding.

* The method to be executed is decided at runtime (runtime polymorphism).

* It improves code flexibility and scalability.

* It helps in writing clean and loosely coupled code.

* Polymorphism eliminates the need for large if-else or switch statements.

* It plays a key role in backend frameworks like Spring Boot.
