# 📘 Day 02 – Variables & Data Types (Java)

## What I Learned
- Difference between **primitive** and **non-primitive** data types
- Memory behavior (stack vs heap)
- Using `var` for type inference (Java 10+)
- Type casting: implicit (widening) and explicit (narrowing)
- Declaring constants using `final`
- Floating-point precision issues in Java

## Key Takeaway
Variables define how data is stored and manipulated in Java.  
Choosing the correct data type improves **performance, readability, and safety**.
