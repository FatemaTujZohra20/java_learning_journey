## Java STREAM API

---

Streams don't store data, they operate on Data.

### What is Stream API?

---
`Stream API is a way to process collections of data declaratively (What to do, not how to loop.)`

### Streams were introduced in Java 8 (1.8.0), because:

---
* Reduce boilerplate loops
* Improve readability
* Enable functional programming
* Easy parallel processing
* Cleaner business logic (very important in Spring Boot services)
