# Day 04 — Loops & Iterations (Java)

## Topics Covered
- for loop
- while loop
- do-while loop
- Nested loops
- Pattern problems
- break & continue
- Loop optimization basics

## Key Learnings
- Choose `for` when iterations are known
- Use `while` when condition-driven
- `do-while` executes at least once
- Nested loops increase time complexity
- Pattern problems build logical thinking
- Optimizing loops improves performance

## Practice Suggestions
- Print number pyramids
- Reverse number patterns
- Prime number checks using loops
- Understand time complexity of nested loops

## Outcome
Strong foundation for:
- Arrays
- Data Structures
- Competitive programming
