### 📘 Day 1 – HelloWorld & main Method Explanation

---

In this lesson, I learned how a Java program starts execution using the `main` method. The `HelloWorld` class is 
a basic Java class that contains the `public static void main(String[] args)` method, which acts as the entry point of 
the program. When the program is run, the Java Virtual Machine (JVM) looks for this main method and begins execution 
from there. Inside the `main` method, I used `System.out.println()` to print messages to the console, which helps verify 
that the program is running correctly. This example helped me understand the basic structure of a Java class and how 
code execution begins in Java.
